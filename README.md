# All Bangla Newspaper Directory (সকল বাংলা সংবাদপত্র ডিরেক্টরি) 📰

A modern, fast, and mobile-responsive Bangladeshi newspaper and media directory built following the structure of [allbanglanewspapersbd.com](https://allbanglanewspapersbd.com/).

![All Bangla Newspaper Logo](assets/logo.svg)

---

## ✨ Features & Directory Structure

Followed and enhanced from **[allbanglanewspapersbd.com](https://allbanglanewspapersbd.com/)**:

1. 🔥 **শীর্ষ ১০ সংবাদপত্র (Top 10 Quick Bar):** Fast 1-click access to the top 10 most-read newspapers and media in Bangladesh.
2. 📰 **জাতীয় দৈনিক (Daily Bangla Newspapers):** Prothom Alo, Bangladesh Pratidin, Jugantor, Kaler Kantho, Ittefaq, Samakal, Amader Shomoy, Janakantha, Inqilab, Naya Diganta, Manab Zamin, Bhorer Kagoj, Desh Rupantor, Alokito Bangladesh, Jaijaidin, Sangbad, Khola Kagoj, Manobkantha.
3. 🗞️ **ই-পেপার (Bangla E-Papers):** Direct shortcut pills linking to online digital e-paper editions (*epaper.prothomalo.com*, *epaper.bd-pratidin.com*, *epaper.jugantor.com*, etc.).
4. ⚡ **অনলাইন পোর্টাল (Online Bangla Portals):** bdnews24, banglanews24, jagonews24, Dhaka Post, Bangla Tribune, Risingbd, Priyo.com, Bd24live, Dainik Shiksha, Newsbangla24.
5. 📺 **টিভি ও লাইভ নিউজ (TV & News Channels):** Somoy TV, Jamuna TV, Channel 24, DBC News, Ekattor TV, Independent TV, News24, NTV, Channel i, RTV, Desh TV.
6. 🌐 **ইংরেজি ও আন্তর্জাতিক (English & World News):** The Daily Star, Dhaka Tribune, TBS, New Age, Financial Express, Daily Sun, BBC Bangla, VOA Bangla, Reuters, Al Jazeera.
7. 📍 **বিভাগীয় ও জেলা সংবাদপত্র (District & Local Newspapers):**
   - **চট্টগ্রাম:** দৈনিক আজাদী, দৈনিক পূর্বকোণ, সুপ্রভাত বাংলাদেশ
   - **সিলেট:** দৈনিক সিলেট
   - **রাজশাহী:** রাজশাহী নিউজ ২৪
   - **খুলনা ও যশোর:** দৈনিক পূর্বাঞ্চল, গ্রামের কাগজ
   - **বরিশাল:** আমাদের বরিশাল
   - **বগুড়া ও উত্তরাঞ্চল:** দৈনিক করতোয়া
   - **কুমিল্লা:** আমাদের কুমিল্লা
   - **কক্সবাজার:** দৈনিক কক্সবাজার
8. 📈 **ব্যবসা ও শেয়ার বাজার (Business & Share Market):** বণিক বার্তা, শেয়ার বিজ, অর্থসূচক, ঢাকা স্টক এক্সচেঞ্জ (DSE).
9. 🏛️ **কলকাতা ও পশ্চিমবঙ্গ (West Bengal & Kolkata Newspapers):** আনন্দবাজার পত্রিকা, বর্তমান, সংবাদ প্রতিদিন, এই সময়, আজকাল.
10. 💼 **চাকরি ও প্রযুক্তি (Jobs & Technology):** Bdjobs.com, সাপ্তাহিক চাকরির খবর, টেকশহর, টেকটিউনস, কিশোর আলো.
11. 📻 **এফএম রেডিও (Bangla FM Radio):** রেডিও ফুর্তি, রেডিও টুডে, ঢাকা এফএম, বাংলাদেশ বেতার.

## 📱 Mobile-First Features

- 🌓 **Dark & Light Mode:** Seamless theme toggling with persistent state.
- 🔲 **Grid View & Compact List View:** Switch layouts with one tap to browse more efficiently on mobile screens.
- 🔍 **Realtime Search:** Instant search across names in Bangla and English, districts, and categories.
- ⭐ **Favorites / Bookmarks:** Save frequently visited papers to your personal list (saved in `localStorage`).
- 🚀 **Zero Dependencies:** Pure HTML5, modern CSS3, and Vanilla JavaScript for instant loading.

## 🚀 How to Run Locally

### Option 1: VS Code Live Server
```bash
code C:\Users\User\.gemini\antigravity\scratch\allbanglanewspaper
```
Right-click `index.html` and click **"Open with Live Server"**.

### Option 2: Browser
```powershell
Start-Process "C:\Users\User\.gemini\antigravity\scratch\allbanglanewspaper\index.html"
```
